# 🐍 Snake AI Project - Quick Start Guide

## What We've Built 🚀

This educational project demonstrates two different approaches to AI:

### 🧠 Expert System (Classical AI)
- **File**: `snake_engine.py`
- **Approach**: Hand-coded algorithms (A* pathfinding, safety analysis)
- **Performance**: ~23 average score, 100% success rate
- **Strengths**: Immediate competence, explainable decisions

### 🧬 Neural Network (Modern AI)  
- **File**: `snake_ai.py`
- **Approach**: Evolutionary neural networks with genetic algorithms
- **Performance**: Requires training (currently low scores, needs more generations)
- **Strengths**: Can potentially discover novel strategies through learning

## 🎮 How to Run

### Quick Demo (Expert System)
```bash
python snake_engine.py
# Choose option 2 for visual demo
```

### Train Neural Network
```bash
python snake_ai.py
# Choose option 2 for quick training
```

### Comprehensive Launcher
```bash
python snake_ai_launcher.py

```

- ✅ Action-based control interface

- ✅ A* pathfinding algorithm
- ✅ Safety analysis (reachable space counting)
- ✅ Strategic decision hierarchy
- ✅ Tail-chasing fallback strategy

### Neural Network Components

- ✅ Population-based evolution

- ✅ Progress tracking and saving
